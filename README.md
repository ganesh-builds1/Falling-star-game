# Falling-star-game
Built my first mobile game this week, mostly by arguing with AI until it did what I wanted.

I had a pretty clear idea of what I wanted to make, but zero patience for writing all the boilerplate myself. So I used AI to generate and clean up most of the code, while I handled the actual thinking — what the game should do, how it should feel, what was broken and why.

Turns out "AI-assisted development" mostly means a lot of testing, a lot of "no, not like that," and rewriting your prompt five times until it clicks. The code came fast. Knowing what to ask for was the actual work.

Few things that stuck with me:

Having a clear idea beats a clever prompt every time
Testing on an actual phone caught way more bugs than staring at the code
"Good enough" and "actually good" are very different bars, and AI will happily stop at the first one unless you push
